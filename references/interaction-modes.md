# 照片与线稿交互模式

线稿应与照片发生物理接触和语义联系，而不是悬浮在照片周围。照片与线稿必须共同描述同一个连续空间。每张图选择一个主要模式，可用一个次要模式补充。

## 连续空间契约

对每个 `continuation` 或 `substitution`，先记录照片边界两侧的对应关系：

```text
Inside segment: 照片内已有的轮廓或结构轴
Crossing point: 它与照片边缘的准确交点
Outside segment: 纸面上继续的同一结构
Continuity: 同一尺度、同一透视、同一方向，以及不变的遮挡顺序
```

至少使用两条可见结构轴完成连接，例如桌面前缘与侧缘、建筑檐口与屋脊、人物肩线与手臂方向。线稿应先沿照片内轮廓行进一小段，再越过边界；边界外只画被裁掉或逐渐替代的部分。若线稿在照片旁边重新描绘一套完整主体、改变尺度或另设消失点，即使线条碰到边缘也不算连续。

## 已确认构图的保护区

当用户明确要求保留某一版的主体或照片—线稿关系时，先把关键建筑、面部、动作、物件、两条结构轴和跨界接缝列为保护区。仅文字、外框、空白纸面或照片的非连接外露边缘可进入修改区；跨界接缝列为保护区，不能被贴纸边、错位色纸层、负形、标题或新线条截断。局部改版的目标是提升一个已有构图层，而不是借机重做已经成立的叙事与空间关系。

## 负形剪纸

`echo` 可以表现为一个与所选纸面同色的负形剪纸，但仅在照片里存在清晰、稳定的主体轮廓时使用：

- 负形轮廓直接取自同一人物、物件或建筑剪影，并可轻微放大、偏移或裁断；
- 负形与真实主体至少局部重叠，让照片、纸面和文字形成真实的遮挡顺序；
- 负形内部优先承载主标题或叙事文字，文字顺着轮廓的宽窄和姿态排布；
- 负形只是一种版面关系，不代表第二个人、第二件物品或第二栋建筑；
- 人物面部、身份特征和关键物件默认仍由真实照片承担，不用负形消除，除非用户明确要求匿名或心理重构。

若照片轮廓松散、主体依靠环境才能识别，跳过负形剪纸，继续使用空间轴线连接。

## 六种交互操作

| 操作 | 含义 | 典型锚点 |
|---|---|---|
| `continuation` | 延续照片中被裁断的真实结构 | 桌沿、地平线、墙角、枝干、衣褶 |
| `emergence` | 从人物或物件中生长出其行为、思想或关联内容 | 头顶、手、工具、乐器、书本 |
| `substitution` | 同一对象从真实照片逐渐转为手绘版本 | 杯子、植物、建筑、衣物、云层 |
| `echo` | 用线稿复述一个关键轮廓、节奏或姿态 | 侧脸、手势、建筑曲面、重复物件 |
| `passage` | 让一条线或一组线穿越照片、留白和辅助图 | 视线、道路、笔迹、声波、结构轴 |
| `annotation` | 以速写标注方式指出照片中的真实关系 | 箭线、圈选、短文字、局部尺寸线 |

通用要求：至少一次交互必须跨越真实照片边界；至少一个线稿必须直接触碰或从可见锚点开始。

## 人物与肖像

锚点优先级：

1. 手部动作和所持物件；
2. 视线方向；
3. 头顶、头发和人物剪影；
4. 肩线、衣褶和身体运动方向；
5. 有依据的职业或创作身份；
6. 用户明确给出的心理或抽象主题。

人物使用 `emergence + passage` 仅在人物动作、手中物件或轮廓是照片里最强的延展锚点时：让相关线稿从动作、视线、衣褶或轮廓出发，再跨越照片与纸面；选择其他锚点时，人物整体保持真实照片，不强行做身体错位或复制。人物面部保持真实可辨，眼睛、鼻子和嘴部周围维持安静区域。

只有用户明确要求心理肖像、双重面孔或情绪重构时，才使用 `echo` 覆盖五官。此时线稿应重新解释表情，而不是逐像素描边。

身份不明确时，只使用可见动作、物件和环境，不推断职业。例如照片里的人拿着笔，可以延展笔迹；不能仅凭服装将其定义为作家。

## 物件与产品

从物件的结构、用途和接触关系中选择锚点：

- 结构：轮廓、接口、把手、鞋带、轮子、开口；
- 用途：书写、播放、盛放、穿着、移动、照明；
- 接触：人物如何握、穿、坐、倚靠或使用它；
- 环境：它所在的桌面、道路、房间或自然场景。

优先使用 `continuation`、`substitution` 或 `annotation`。不要围绕产品加入与使用情境无关的通用装饰。

## 空间与环境

从透视和空间骨架接续：

- 桌面、地面、墙线和建筑边缘继续向纸面延伸；
- 植物、山体、道路和水面保持原有方向；
- 照片内的消失点、水平线和遮挡顺序不被重新发明；
- 复杂环境只保留一条主结构与一至两个关键物件。
- 先延续照片中最稳定的两条空间轴，再添加物件；物件的位置、接触面和遮挡关系必须由这些轴线推导。

默认使用 `continuation + substitution`。先选择照片中最稳定、最具语义的结构轴或主体局部；线稿可以补全未拍到的空间或逐步替代墙画、建筑、物件等局部，但补全部分必须明显来自照片，而不是另画一个独立场景。

## 人物与作品的混合叙事

当辅助图是人物的作品、地点或行为结果时，可建立：

```text
人物 -> 手绘思考/动作 -> 作品照片
```

让线稿承担中间状态：既接触人物，又进入作品照片。人物和作品不能成为两个互不相关的拼贴块。

## 密度控制

- 每张图使用一条主链，一至三个语义元素族。
- 一个主线稿群负责叙事，一个辅助线稿群负责平衡或接续。
- 快速乱线只用于表达确有来源的思考、运动、声音或结构推演。
- 快速乱线只用于表达确有来源的思考、运动、声音或结构推演；不能用箭头、圆圈或独立速度线替代照片到手绘主体的连续轮廓。
- 在人物面部、关键产品细节和重要文字附近主动降低密度。
- 空白区域用于分隔视觉想法，不用小图标填满。
