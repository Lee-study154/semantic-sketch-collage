# 文字系统

文字既是内容，也是方向、尺度和节奏。它必须沿照片主体和线稿关系生长，不能作为最后贴上的普通标题框。

## 内容模式

### Exact

用户提供了文字时：

- 原样保留字符、大小写、数字、标点和语言；
- 不主动翻译、润色、添加副标题或署名；
- 不把用户提供的正文替换成更“文艺”的句子；
- 用户提供多层文字时，先按主标题、次标题、信息文字建立层级。

### Grounded

用户未提供文字时：

- 从可见场景或用户背景中提炼一个短标题，可再加入一至三组描述同一主体的辅助短语；
- 英文通常为一至五个词，中文通常为十个汉字以内；
- 优先具体名词、动作、材料、时间感和空间关系；
- 不使用人物姓名、引语、地点、品牌、日期和事件信息，除非用户已提供；
- 找不到可靠而有价值的内容时，切换为 `None`。

### None

用户说“不要文字”时，画面中不得生成标题、伪文字、装饰字母、日期、编号或水印。线稿独立完成叙事。

## 字形语言

中文与日文标题优先遵从下节“用户固定字形参考”；以下通用规则用于英文、其他文字及未指定的辅助层级：

- 默认字形窄长、不等高、轻微倾斜，字符宽度和间距故意不均，像用干涩签字笔或磨损毡尖笔快速写成；
- 基线明显但受控地起伏，部分字母前后错位，笔画保留停顿、回勾、重复压线和偶尔断墨；
- 避免圆润展示字、泡泡字、统一粗细、整齐基线、完美等距和接近现成字体的规整字形；
- 标题可绕人物轮廓、沿视线、动作或建筑轴线排布；
- 允许水平、倾斜、弧形和垂直方向，但每组文字只服从一个清楚方向；
- 主标题使用中到大号手写字建立重心；辅助文字从同一手工印刷语境中更换工具、粗细和节奏，不要求所有文字像同一支笔写出；
- 浅底使用黑字，深底使用白字，跨背景时保持连续可读；
- 混合语言只在用户提供或明确要求时使用。

## 用户固定字形参考

用户在 2026-09-09 指定后续中文、日文标题的字形样式完整借鉴以下两张图。按语言分别生效，不要求两种语言同时出现；后续用户的新指示可覆盖这一默认。

| 标题语言 | 本地视觉参考 | 必须落实的字形特征 |
|---|---|---|
| 中文 | [中文标题手写参考](lettering-chinese.png) | 斜向行进、行草式连带与舒展长笔画，笔压和粗细反差明显，尖锐收笔、干笔飞白和断墨；字符大小、宽窄与基线自然变化，整体流动且准确可读。避免退回均匀细线的工程速写字或规整印刷字。 |
| 日文 | [日文标题随写参考](lettering-japanese.png) | 细至中细笔的日文随写体，疏松字距、不等大的汉字与假名、轻微歪斜、朴拙比例；保留起收笔、局部墨团和粗糙缺口，轻松且略带稚趣。避免中国书法式的浓重连笔与整齐书道章法。 |

- 制作包含对应语言标题的作品前，先读用户照片，再查看对应本地参考。两张图仅作为字形标准，不复制其示例文案、空白版式或其他内容，也不作为图像 API 的附加图片；将笔触、字形和间距特征编译成文本提示。
- 字形样式固定，排版依据当前照片：日文不因示例竖排而强制竖排；中文可按构图分行、倾斜或调整字距，不能因此丢失参考的笔势。
- 主标题与次标题仍须拉开字号、粗细和视觉重量。用户允许的辅助中文可采用较细旧字样式；不要把每组文字都放成同等大的主标题。
- 英文与对应中文/日文标题协调，但通常更小、更轻；只在用户要求时添加对应语言。逐字检查，不以“手写感”解释错字。
- 主次按实际视觉重量验收，不能只比较字号：面积、墨色覆盖、粗细、位置与周围留白都会影响抢眼程度。日文被指定为主标题时，日文必须成为第一文字入口；英文即使换用印刷字或粗体，也要缩小、减少黑色面积或降低对比，不能用大块粗黑英文压过细笔日文。加强日文可用更大的字符尺度、局部笔压和位置关系，仍保持固定参考字形。

## 多语种标题

用户明确要求日文、英文或其他多语种标题时，先为每种语言建立独立的 `Exact` 文本组：各自保持原文、字符顺序和可读性，不翻译、不互换、不用伪文字填充。日文与英文可以分别承担主标题和辅助标题，或形成不同的展示字、叙事字声部；通过字号、粗细、方向和留白区分层级，让两种语言共同服务同一条照片叙事链。生成后逐字符核对每种语言，尤其检查日文汉字/假名是否缺失、英文是否被截断或拼错。

用户要求轻松、随性或稚拙趣味时，日文使用**日文随写体**：细笔为主，字形略小且不等大，笔压不匀，字符间留出明显呼吸，允许轻微歪斜、犹豫、回笔和幼稚但可读的比例。避免中国书法式的粗重笔锋、正式竖幅章法、浓墨飞白、对称中轴和过于工整的书道作品感。配套英文使用更小、更轻的窄长随写大写或微型打字体，通过字号和重量从属于日文主标题；两种语言之间保留明确留白，不挤成同一块标题墙。

文字的随性来自位置、比例和笔触，不来自拼写错误或不可读。

## 三种文字声部

当用户要求丰富排版、手帐感、zine 感或画面需要多个文字重心时，从展示字、叙事字和微型注释字中选择至少两种，最多三种：

| 声部 | 视觉特征 | 作用 |
|---|---|---|
| 展示字 | 粗黑磨损马克笔、字符尺度差异明显、短词 | 建立第一视觉重心 |
| 叙事字 | 窄长手写大写、轻中等粗细、基线歪斜 | 承载一句或分行短语 |
| 微型注释字 | 小号打字机感、针管笔小写或紧密手写 | 平衡角落、连接局部信息 |

同一作品使用至少两种字号、两种粗细和两种字形节奏；最大文字与最小文字的高度建议形成约 3:1 至 6:1 的反差。颜色、纸纹、笔触缺口或重复描线保持共同来源，使变化形成家族而不是字体样张。

当主标题需要更强的海报重心时，使用**高窄、粗黑、磨损感**的短词展示字：字符可被压缩、拉高、轻微错位并保留干刷缺口，但仍完整可读。让它与窄长叙事字、微型打字注释和一组沿结构轴的松弛手写字形成不同声部；不要把所有文字都变成相同的细长速写字，也不要让标题遮挡主体事实。

## 布局规则

- 标题优先进入视线前方、头部外围、动作出口或线稿形成的负空间。
- 不覆盖眼睛、嘴部、关键手势和产品识别细节。
- 标题可成为第一或第二视觉入口；信息文字必须从属于照片主体。
- 文字应与至少一个照片轮廓、线稿方向或构图轴对齐。
- 不为填补空白而增加标签、坐标、档案编号和伪编辑信息。
- 默认组织两至四个不对称文字组：一个主标题、一至三组辅助短语。文字组可部分进入负形剪纸、照片边缘或结构线形成的空间；至少一组与另一组在字号、粗细或字形上形成明显区分。允许对有意义的词做歪斜下划线、不闭合圈注、轻微划改或重复一遍；装饰动作必须服务阅读顺序。
- 用户要求丰富排版时，结合可见事实选择一至两组补充短语，明确主标题、语言辅助和微型注释的层级；不要把增加信息误解为复制同义标签，或把一个主标题加一个英文标题固定摆在两个孤立角落。
- 至少一组文字沿主体外轮廓、视线、空间轴或留白形状形成环绕、错行或方向变化。可在非交互边缘建立轻微前后关系：文字横跨纸面与局部色纸，或由照片轮廓遮住少量字尾/下划线；保持每个字符完整可辨，面部、手脚、风扇等关键事实与转绘接缝不被标题挡住。不为制造遮挡而添加无来源主体轮廓。

## 精确文字的两阶段策略

当文字包含重要姓名、日期、品牌、中文长句或必须零错误的内容时：

1. 先生成保留明确文字空间的无字或占位版本；
2. 再使用可控的排字或编辑方式加入准确文字；
3. 逐字符核对最终图片；
4. 若无法保证准确，交付无字版本并明确说明，不把错误文字当成完成品。

短而宽容的情绪标题可以直接进入图像生成提示，但生成后仍需核对。

## 文字检查

- 内容是否来自用户或可靠照片信息；
- 所有字符是否完整、正确、可读；
- 文字方向是否由人物、动作或构图决定；
- 标题是否与线稿和照片发生关系；
- 删除文字后是否损失叙事，而不仅仅损失装饰。
