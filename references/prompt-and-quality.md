# Prompt Compiler 与质量门槛

## 生成前决策对象

在内部准备以下对象，不必默认展示给用户：

```text
Canvas: 根据原图选定的浅色纸面、取色依据、方向、比例、照片占比、裁切位置和留白
Truth: 必须真实保留的主体与关系
Narrative chain: 唯一主要叙事链
Interaction map: 每个线稿的来源、锚点、操作和功能
Continuity map: 照片内线段、边缘交点、纸面延续、尺度、透视和遮挡顺序
Photo treatment: 默认保留原图原色与光线、抠图、辅助照片角色、是否使用源于主体轮廓的负形剪纸
Cutout layers: 断续纸边宽度、源图取色的局部叠层、露边位置、接缝避让与视觉主次
Drawing system: 黑/白线、密度、笔触和跨界路径
Lettering: Exact / Grounded / None、文字、方向、层级和空间
Internal style cues: 从 bundled examples 提炼出的少量可见行为；只进入文本提示
Avoids: 当前图片最容易出现的具体失败
```

## 四段式提示词

最终发送给图像生成工具的提示应只包含能成为可见像素的指令：

1. **纸面与真实照片：** 先说明根据原图选定的浅色纸面覆盖整张输出；选淡米白时强调近中性、少黄，也可选雾蓝灰或其他协调纸色。再说明原照片只作为局部照片块/窗口/抠图主体、占比、位置和裁切；列出必须保留的原图原色、物理光线线索、面部、动作、物件、建筑结构与透视。
2. **语义链与交互：** 说明线稿画什么、为什么出现、从哪个照片内轮廓开始、在哪个边缘交点跨界，以及跨界前后如何保持同一尺度、透视、方向和遮挡关系。
3. **视觉与文字：** 大胆实验编辑风格、线条明暗切换、疏密、被激活的留白、照片与纸面协调的色彩/颗粒，以及主标题和辅助短语的准确内容、手写笔触、层级与排布方向。明确稍宽断续纸边与少量错位叠色的具体位置、取自照片的颜色，并让全部边缘层避开照片—线稿接缝；照片原色与线稿延续始终主导。
4. **约束：** 明确禁止当前场景最可能出现的随机装饰、身份虚构、脸部损伤、伪文字、机械描边、无关元素，以及全幅照片加线稿覆盖。

提示应描述当前这张照片，而不是堆叠通用风格关键词。不要把文件路径、分析术语、打分过程或设计理论写进最终提示。

## 运行时图片输入

图像输入集合必须严格等于用户为当前作品提供的图片集合：

1. 用户上传一张图片时，只传这一张，作为编辑目标和唯一事实来源；
2. 用户明确提供多张图片时，才按其要求区分主图与辅助图；
3. bundled examples、skill assets 和内部风格示例永远不作为图片参数，也不上传到外部服务；
4. 内部示例只用于提炼构图、线条、文字和跨边界交互的文本描述。

调用图像工具前，逐项核对图片参数的来源；任何不是用户为当前作品提供的图片都从调用中删除。

用户一次上传多张待测照片但未要求合成时，分别执行单图工作流：每一次调用只携带该次的唯一照片，不交叉传入另一张待测照片。

## 锁定底图局部改版

适用于用户确认一版主体、照片—线稿交互或底图色调，只要求替换文字、外框、注释、纸边或局部边缘叠色的情形。

1. 从确认版本标出保护区与可编辑区；保护区至少包括主体、关键细节、两条连续结构轴及其跨界接缝。
2. 使用局部遮罩仅开放文字、页边框和不触及接缝的照片外露轮廓。遮罩只是生成的修改许可，不是设计元素。
3. 生成后对比草稿与底图；遮罩外像素从已确认底图原样回贴，确保未授权区域不因模型漂移而变形。
4. 检查新增的框线、标题、贴纸边和错位色纸层没有切断跨界路径，也没有把照片重新读成独立卡片。

## 执行流程

1. 检查 Semantic Visual Card 是否只使用 A/B 级事实。
2. 确认交互图中每个元素都有 `Evidence + Anchor + Function`。
3. 核对运行时图片集合只含用户为当前作品提供的图片。
4. 编译四段式提示并使用 `imagegen` 生成或编辑图片。
5. 在正常尺寸检查主体、线稿连接和文字；在缩略图检查主次和整体张力。
6. 若存在一项明确失败，修改对应提示字段并定向修正一次。
7. 返回图片和一至三句中文创作说明。

## 安全拒绝与本地叠加 fallback

- 图像服务返回安全拒绝时，不得通过改写、弱化或隐藏内容来绕过安全系统，也不降低安全设置反复重试。
- 需要继续处理同一照片时，保留原照片在本地，不再把它发送给被拒绝的服务。
- 从 Semantic Visual Card 取得锚点和构图坐标，只生成不含原照片、人物身份或敏感场景的独立线稿素材；无法安全生成素材时，改用本地程序化线条。
- 在本地把线稿、准确文字和轻量纹理合成到原照片上，保持原照片像素、人物身份与事实关系不被重新生成。
- 交付时说明使用了本地叠加 fallback；不得把它描述成模型成功编辑了原照片。

## 质量门槛

所有项目都通过才可交付：

- **真实性：** 主体、面部、动作、物件和关键空间关系仍然可信可辨；默认保留原图原色和光线，没有因黑白参考而去色或把照片统一染成底色。
- **纸面优先：** 根据原图选择的协调浅色纸面是第一画布层，照片是局部嵌入而非全幅背景；纸面在缩略图中仍占明显面积，米白少黄、近中性，雾蓝灰与其他纸色不跳脱。
- **裁切：** 环境/物件照片块通常覆盖纸面约 20%–45%，人物抠图可约 35%–65%；裁切保留核心证据且不是居中相框式展示。
- **叙事：** 画面能用一条清楚的因果链解释。
- **来源：** 每一组线稿和文字都能指出照片或用户背景中的依据。
- **锚定：** 线稿确实从人物、物件或空间的具体位置开始。
- **交互：** 至少一次线稿跨越照片边界，照片与绘画不是两个独立图层。
- **空间连续：** 至少两条真实结构轴在照片内出现、穿越边缘，并以相同尺度、透视和方向继续；没有在照片块旁边另画一套完整主体。
- **主体延续：** 主要线稿群必须是照片中选定的同一人物、物件、墙画或空间结构的局部替代/补全；锚点由照片结构决定，不默认选择人物。它在照片内先沿真实轮廓行进，出边后逐步简化，不能由独立箭头、圆圈、速度线或抽象轨迹承担主体交互。
- **材质连续：** 照片与纸面共享扫描颗粒或印刷质感，至少一个来自照片的颜色或线条动作跨越图层。
- **层级：** 一个主体占主导，大胆但不平均拥挤。
- **线稿密度：** 细节丰富的照片主体转为手绘时，线稿只保留少量关键轮廓、姿态和结构节点，笔触随性、稚拙、开放；不得变成写实素描或密集解剖排线。
- **视觉重心：** 主照片锚点与其连续线稿共同形成唯一第一重心，文字和色块有清楚的第二/第三层级；没有多个等量争抢的标题、色块和注释组。
- **人物保护：** 普通模式不破坏关键五官和表情。
- **文字：** 内容准确、可读、方向合理；默认手写字窄长、参差、间距不均，有清楚的主标题与辅助文字层级；`None` 模式没有伪文字。
- **文字层级：** 丰富排版模式至少两种字号、两种粗细和两种字形节奏；各文字组位置错落但共享笔触、纸纹或颜色来源。
- **负形依据：** 使用负形剪纸时，其轮廓能对应真实主体，并与照片发生明确遮挡或连接；它没有被误读为新增主体。
- **输入边界：** 图像工具收到的每张图片都来自用户当前请求，没有 bundled asset 或内部示例。
- **参考独立性：** 未复制参考图的人物、现成文字或完整布局。
- **局部改版：** 已锁定的主体、连续结构轴与跨界接缝保持原样；贴纸边只出现在非连接外露轮廓，外框保持断开、越界、转角不完全闭合的手绘节奏。
- **抠图可见性：** 稍宽的断续纸边与局部错位叠色在正常尺寸下清楚可辨，边宽随主体尺度调整；颜色来自原图，可露出窄条、角部、刷痕或中等面积底纹，无整圈厚白描边、立体阴影或覆盖整页的纯色底板。
- **边缘从属：** 缩略图先读到原色照片、选定主锚点与跨界线稿，色纸层作为版面重心的一部分但不遮蔽主体；纸边和全部色纸层都在连续结构接缝处退让。
- **缩略图：** 主体和主线稿群仍然清楚，没有退化成噪点。
- **完整编辑版式：** 纸色有源图依据且不是惯性近白；手绘接管可识别的真实形态，默认外框和源色点缀参与构图。不能仅凭文字正确、像素未变或几根结构线接上就判为视觉通过。
- **语言主次与空间排字：** 指定的主标题语言在缩略图中仍为第一文字入口，英文不能因粗黑抢眼；多个文字组围绕同一主体或空间动线组织，适量层叠不挡事实与转绘接缝。Vox 层位于非交互侧，纸边不能平均环绕所有边缘。

## 定向修正

| 失败 | 只修正这些内容 |
|---|---|
| 随机涂鸦 | 删除无 Evidence/Anchor/Function 的元素，仅保留主链 |
| 线稿悬浮 | 把起点移到明确轮廓或动作锚点，并让同一对象在照片内先延续一段、再跨越边界；删除独立箭头、圆圈和抽象速度线 |
| 图层割裂 | 选两条照片内结构轴，标出边缘交点，以同尺度和同透视继续；让线或文字压过局部照片边缘，并统一照片与纸面的颗粒和强调色 |
| 旁边重画主体 | 删除独立副本，只保留照片中被裁断部分的连续线稿；先画共享轴线，再补局部细节 |
| 机械描边 | 删除大部分完整轮廓，改用局部重复线、延展和中断 |
| 主体受损 | 恢复照片细节，降低脸部和关键物件附近的线稿密度 |
| 构图太弱 | 放大主体或主线稿群，增加尺度与方向反差，不增加新主题 |
| 构图太满 | 删除辅助元素，恢复一个安静区和清楚视觉路径 |
| 像照片滤镜 | 重建与原图协调的浅色纸面，将照片裁成局部块并裁减真实天空/墙面等大面积背景，保留一个有物理来源的光线线索，让线稿从裁切边缘补全空间 |
| 背景偏黄或跳色 | 米白提亮并降低黄感；其他纸色重新依据原图取色，只调整背景，不把照片去色或染成同色 |
| Vox 抠图不明显 | 在非连接外露轮廓稍增纸边宽度或明度差，补少量原图取色的错位露边，保持接缝开放 |
| 边缘色块抢主体 | 保留源色叠层的版面功能，先降低饱和度、拆分成贴着真实结构的刷痕/纸片，再调整面积；不要把它删除到只剩不可见的细条 |
| 文字错误 | 使用 Exact 内容重做；重要文字转为两阶段排字 |
| 字体太规整 | 改用窄长参差的干笔手写，打破基线、间距和字符高度，加入少量有意义的下划线或圈注 |
| 文字仍然单调 | 在展示字、叙事字和微型注释字中选择两至三种，拉开字号与粗细，并让一个文字组进入负形或跨过照片边缘 |
| 线稿过于写实 | 删除解剖明暗和密集排线，只保留姿态轮廓、关键结构节点和少量重复手绘线；降低细节密度，加入松散、稚拙、犹豫的笔触 |
| 元素过多无重心 | 只保留一个主标题、一组英文辅助和一组服务主锚点的色块；删除或缩小多余注释、边框和第二色域，恢复主照片与延展线稿的第一阅读层 |
| 留白无张力 | 用一至三组有依据的辅助短语、不闭合描边或延续轴线建立对角张力，不添加无来源图标 |
| 风格照搬 | 恢复用户照片结构，仅保留参考中的转换行为 |

## Hard Avoids

Avoid full-bleed source photography, full-photo line-art overlays, blueprint treatment, a complete duplicate subject drawn beside the photo, scale or perspective resets at the photo edge, an invented silhouette unrelated to the photo, random doodle stickers, unrelated stars and arrows, generic scrapbook decoration, invented identity, fake quotations, pseudo-editorial metadata, meaningless handwritten text, every text group using the same size and weight, rounded display lettering, perfect baselines, uniform character spacing, illegible spelling, full-photo tracing, smooth uniform vector strokes, cute cartoon outlines, arbitrary face obstruction, decorative elements with no source anchor, timid peripheral doodles, multiple unrelated narratives, detached photo and drawing layers, centered framed-photo layouts, crowded filler, copied reference subjects, copied reference wording, logos, watermarks, glossy mockups, fake 3D paper depth, neon glow, and cinematic depth of field.

## 默认输出

```markdown
![语义延展式手绘拼贴](absolute-image-path-or-rendered-image)

**创作思路**

[用一至三句中文说明主要叙事链、关键锚点以及照片与线稿如何互相延展。]
```

只有用户明确要求时，才额外提供最终提示词、Semantic Visual Card 或逐项质量检查。
