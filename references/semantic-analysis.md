# Semantic Visual Card

在查看任何 bundled work 之前完成本卡。目标不是为照片编故事，而是找到真实内容能够支持的视觉延展。

## 证据等级

| 等级 | 来源 | 可用于什么 |
|---|---|---|
| A | 用户明确提供的身份、事件、主题、作品和文字 | 可作为叙事事实和线稿主题 |
| B | 照片直接可见的人、动作、物件、空间、光线和方向 | 可作为形态与场景事实 |
| C | 合理但无法验证的职业、关系、地点、情绪或经历 | 只能作为模糊气氛，不能写成事实 |
| D | 照片和用户都未提供的信息 | 不得生成 |

不得根据长相识别人物，也不得自行补充传记、引语、品牌、日期和地点。对表情只描述可见状态，如“低头、凝视、闭眼”，不做心理诊断。

## 卡片字段

生成前在内部解析以下字段：

- **Primary photo:** 主照片；多图时默认第一张为主图，除非用户指定其他角色。
- **Supporting photos:** 仅记录与主图存在明确人物、作品、地点或事件关系的辅助图。
- **Core subject:** 保持画面身份所必需的一个主体。
- **Supporting evidence:** 最多三个强化场景或身份的可见元素。
- **User context:** 用户提供且允许进入画面的背景事实。
- **Protected details:** 面部、手势、文字、产品特征或空间关系中不可破坏的部分。
- **Dominant gesture:** 视线、手臂、身体姿态、道路、桌沿、建筑线或光影形成的主要方向。
- **Natural anchors:** 线稿可以真实接入的轮廓、端点、边缘、遮挡关系和画面出口。
- **Quiet fields:** 允许承载线稿或文字的天空、墙面、地面、暗部和留白。
- **Semantic candidates:** 能由 A/B 级证据支持的关联物、行为、空间或概念。
- **Uncertainty boundary:** 明确哪些内容不能推断。

## 建立主要叙事链

把候选内容写成一条可读的因果链：

```text
事实主体 -> 可见或已知行为 -> 延展内容 -> 叙事含义
```

示例：

```text
建筑师 -> 构思与画图 -> 头顶建筑草图 -> 思想成为空间
握笔的人 -> 书写动作 -> 笔迹越过照片边界 -> 语言改变周围环境
咖啡桌 -> 桌沿与杯子 -> 线稿桌面和餐具 -> 被裁掉的空间继续存在
```

只有同时满足以下条件的候选才能成为主链：

1. 与核心主体直接相关；
2. 能找到照片中的物理锚点；
3. 能形成清楚的视觉动作；
4. 不依赖未经验证的身份推断。

若多个候选同样成立，选择最短、最具体、最能产生照片—线稿跨界关系的一条。其余内容只可作为同一叙事链的辅助，不另起主题。

## 交互图

为每个计划新增的元素记录：

```text
Element: 要画或写什么
Evidence: 对应的 A/B 级来源
Anchor: 从照片哪个具体位置发生
Operation: continuation / emergence / substitution / echo / passage / annotation
Function: 连接、引导、平衡、补全、解释或强调
```

任何缺少 `Evidence`、`Anchor` 或 `Function` 的元素都从方案中删除。

## 多图输入

- 用户已指定主图和辅助图时，严格按其角色使用。
- 用户未指定但关系明显时，第一张为主图，其余只补充作品、地点或结果。
- 多张图片没有明确关系时，不把它们自动拼成一张；先以第一张完成单图方案，除非用户请求多图拼贴。
- 辅助照片必须推进同一叙事链，不能只用于填满版面。
- 这里的“多图”只指用户为当前作品明确提供的照片；bundled works 不是辅助照片，也不进入运行时图片集合。
