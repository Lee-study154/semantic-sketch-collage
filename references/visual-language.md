# 视觉语言与作品资产路由

## 风格定位

目标是大胆、随性、粗粝而有思考性的实验编辑拼贴，接近艺术展览海报、建筑师速写、独立杂志和朋克刊物之间的状态。构图骨架默认克制，笔触默认大胆：用大面积纸面留白和少量照片建立秩序，再用粗黑、带速度感的线条制造张力，而不是把整页填满。

## 照片层

- 根据原图配色先建立浅色纸面，具体选择见“背景与边缘叠色”；照片只占纸面的一部分，作为被裁切的现实证据，而不是整张作品的背景。
- 环境或物件照片块通常覆盖纸面约 20%–45%，以留出足够纸面让空间被线稿补全；人物主体抠图可覆盖约 35%–65%，以保持肖像主导。使用一个主照片块、局部窗口或主体抠图；除非用户明确要求，不做全幅照片加线稿覆盖。
- 主体照片保持真实纹理、身份与原图原色，可大胆裁切、放大或抠图；不为模仿黑白拼贴参考而去色。
- 保留原图的主色、肤色和冷暖光线关系。纸面和边缘叠色可提亮、降低饱和度；照片本身只做维持连续印刷质感所需的轻量颗粒或明暗协调，不默认套低饱和滤镜或压掉逆光。
- 人物同样默认保留原色；只有用户明确要求或源图本身为黑白时才使用黑白处理。
- 辅助图只在它承担作品、地点、结果或现实证据时使用。
- 不把照片降格为模糊背景纹理；至少一个核心主体必须在正常尺寸和缩略图中都可辨认。
- 输出比例由纸面版式决定，不受源图方向束缚；横图可以裁入竖版纸面。始终重新裁切而不是拉伸。

## 线条层

- 使用黑色、暖黑、深灰和白色线稿；背景变暗时切换为白线，背景变亮时使用黑线。
- 主轮廓默认使用粗黑毡尖笔、油性笔或粗铅笔般的力度，线宽有明显变化并在转折处留有停顿、墨团和重复压线；辅助结构可更细，但不能整体退化成轻薄工程制图线。
- 保留手绘速度：轻微抖动、粗细变化、断线、回勾、重复描线和局部错位。
- 对照片里本身细节丰富的主体，线稿只保留能证明姿态、方向和身份的少量轮廓与结构节点；用松散、稚拙、带犹豫的笔触替代写实素描、解剖明暗和密集排线。线稿细节密度应低于照片细节密度，避免把延展对象画成精细插图。
- 建筑、思想或运动可使用快速重叠的探索线；普通对象使用更少、更清楚的轮廓。
- 一条线可以穿越照片、纸面和另一张照片，但在明暗背景之间保持可见。
- 线稿优先从照片裁切边缘上的真实结构接出：屋脊、飞檐、桌沿、墙角、植物枝干、人物轮廓或手中物件。它在纸面上继续同一对象、补全缺失空间或把真实结构逐渐替换为速写。
- 跨界采用“照片内接线 -> 越过边缘 -> 纸面延续”三段式：线条先进入照片内部一小段并贴合真实轮廓，再跨过裁切边缘，最后以相同尺度、透视和方向继续。照片边缘在连接处可被线条、文字或局部遮挡打断。
- 线稿的主要面积应是照片中最有结构延展潜力的同一对象，从照片到速写渐变延续。先比较人物轮廓、动作物件、墙画、招牌边缘和空间轴，选择最能形成连续视觉动作的一至两个锚点；不能因为画面有人物就默认把人物身体做成错位副本。照片里的选定结构先保持一段真实轮廓，再在边缘外逐步减少细节、保留同一姿态、透视和受力方向，形成局部替代或补全。
- 不用独立箭头、圆圈、速度线或抽象轨迹代替连续结构。若主题是动作或风，线条也必须从真实手势、衣褶、物件出口或空间边界出发，并在同一对象上结束；只有极少量短线可作为辅助节奏，不能成为主线稿群。
- 不使用光滑统一的矢量描边，不把整张照片机械描边。
- 手绘需要足够的形态与覆盖范围，让观者认出照片的哪部分由手绘接管。优先形成一个主转绘对象群，可加一个有来源的环境接续群（例如窗框、帘褶、窗台或地面），用重复探索线、局部排线和粗细层级增加手迹。避免把“简化”执行成只剩几根定位线；丰富的是同一场景的结构，不是无关元素数量。

## 构图层

- 纸面是第一画布层；以非对称、偏心、越界和尺度反差组织照片块、线稿与文字。
- 人物可占据大面积并被页面边缘裁切；标题、线稿和辅助图围绕主体组织。
- 用视线、手势、轮廓、透视线和文字方向建立连续眼动路径。
- 允许一个高密度线稿区与一个明显安静区并存。
- 默认让纸面保留约 35%–55% 的安静空白；线稿可以粗重，但元素数量保持少，形成“少而有力”的节奏。
- 每张图只设一个视觉重心：主照片锚点与其手绘延展共同承担第一阅读层，标题、色块和辅助字围绕它服务。若文字、色块和线稿同时抢第一眼，删除或缩小辅助组，恢复明确的大小、重量和留白差。
- 留白必须被视线方向、结构轴、文字组或不闭合描边激活；不能留下与主体没有张力关系的大块空洞区域。
- 照片边缘可以是干净裁切、自然矩形或局部抠图；只在选定外露边缘加入纸层，不把每条边统一包上撕纸、胶带或贴纸白边。
- 本项目使用克制但可辨的 Vox 抠图边缘；纸边宽度、局部叠色和接缝避让见“背景与边缘叠色”。
- 照片块不能像居中的相框或卡片；至少一处照片结构要跨出裁切边缘，转为手绘线稿并占据纸面空间。
- 主体拥有清晰可识别的外轮廓、且文字需要进入主体区域时，可加入一个来自同一轮廓的纸面色负形剪纸。负形与真实主体应局部重叠或错位，承载文字并暴露纸面；它不是复制照片，也不新增人物或物件。
- 改变纸面或整体色调时，保留一个源图光线线索，例如逆光、窗光、暖色地平线或局部高光；把它限制在有物理来源的区域并向纸面渐隐，使新配色仍保留原照片的时间感与情绪。
- 本项目的编辑海报默认纳入一组细黑手绘外框，距短边约 `4%–7%` 仅作起点；它组织页边、眼动与文字层级，可被主体或标题压住，保留断开、越界、转角不完全闭合的笔触，不画成规整卡片边框。用户要求无框或构图确实不适用时省略，不能因追求极简自动删掉已偏好的外框。

## 色彩与材质

- 黑白线稿是默认骨架，照片默认保留自然原色；背景与边缘配色围绕照片协调。
- 可选一个来自照片的强调色，用于连接照片、线稿或文字；没有结构作用时不用强调色。
- 允许扫描颗粒、复印噪点、干墨、铅笔和轻微错版，但纹理保持从属。
- 保持平面编辑设计，不使用立体纸张阴影、浮层卡片、霓虹发光和电影级景深。

## 背景与边缘叠色

- 用户已允许逐图自行选择背景，无需每次询问颜色。淡米白与已认可的雾蓝灰继续保留为候选，也可从源图主色取样提亮、降饱和，选择中性浅灰、灰白或其他协调的浅色纸面；以原色照片、线稿和文字的清楚对比为准。
- 米白比旧版更淡、更少黄，接近中性纸白，可从 `#F6F5F1` 附近试起；这是调色起点，不是固定模板。参考图的浅纸白与灰白可借鉴，不沿用明显奶黄、茶染或复古泛黄。雾蓝灰沿用已认可方向，随原图微调。
- “米白少黄”不是“所有图都更白”。背景需要可辨的纸面色调：根据原照片选择淡米白、雾蓝灰、灰绿或其他协调浅色；若大块近白留白使照片和文字漂浮，优先调整纸面色相与明度及版面关系，不能只添加噪点。调色作用于纸面，不统一染色照片或压掉真实逆光。
- Vox 基础纸边只出现在非连接外露轮廓。不规则米白贴纸边调为近中性的淡米白，也可使用与底色协调、仍可辨认的浅纸色；建议从输出短边约 `0.5%–1.0%` 的宽度起步，比旧版稍宽，按主体尺度调整。边缘宽窄不均、局部裁断，避免整圈等宽厚白描边。
- 在选定结构下方或旁边叠一至两层略错位的源色纸片、干刷色带或半透明底纹；它们可以形成中等面积的局部色块、刷痕和裁切层，建议单个色域约占纸面 `3%–12%`，但必须依附墙画、招牌、人物衣物或照片裁切轮廓。允许边缘有轻微撕口、干墨和印刷错位，颜色取自原图已有颜色并适度降饱和。
- 叠色遵循 `Evidence + Anchor + Function`：颜色来自照片，形状依附真实结构或裁切轮廓，作用是强调主锚点、承接照片到线稿的替代或组织版面。照片原色仍是主要色彩信息；不把叠色扩张成覆盖整页的背景板、无来源独立圆形或抢走主体的单一高饱和色团，也不为仿参考添加报纸碎片、现成文字或无依据装饰。
- 原图与手绘延续始终优先：纸边和色纸层在结构接缝处同时断开或退让，让线条先进入照片内轮廓、再自然越界；不靠色块遮盖连接问题。保留源图的局部暖光、逆光等物理光线线索。
- 先在交互图标出转绘侧，再选择其他外露轮廓做 Vox。左侧承担转绘时，Vox 可放右侧和下方的非连接局部；这是一条空间分工规则，不是固定左右模板。纸边、叠色不沿全周平均铺开；保留一至两处清楚可见的源色纸片或干刷点缀，连接主体、辅助文字和外框，避免退化为均匀衬边或不可见细条。
- 缩略图先读到原色主体、主锚点和跨界线稿，正常尺寸再看出色块、纸边和叠层的关系。若色块先于主体被注意到，降低饱和度或缩小色域；若画面失去参考图那种照片、速写和色层共同构成的版面重心，先恢复局部色带或刷痕，再调整面积。
- 作品资产只用于观察边缘压叠、错位露色和浅色纸底等行为。强色块支撑黑白照片的做法不适用于本项目的原色照片；成品仍只转成文字规则，不作为后续测试图的图像输入。

## 版式骨架

默认先确定这四层，再决定具体元素：

1. **纸面：** 与原图协调的浅色纸底覆盖整张输出，是最大面积与主要留白；淡米白少黄，雾蓝灰和中性浅灰均可按图选择。
2. **照片：** 一个局部照片块或主体抠图；环境/物件通常覆盖纸面约 20%–45%，人物可放大到约 35%–65%，保留最能证明主体的结构。
3. **跨界线稿：** 从照片内的可见锚点开始，越过至少一条照片边缘，以相同尺度和透视补全或替代同一结构；不在旁边重画一个副本。
4. **文字：** 一组主标题与一至三组辅助短语沿主体轮廓、结构轴、负形剪纸或线稿方向进入版面；用不同字号、字形节奏、粗细、错位基线和局部圈划制造节奏，没有可靠内容时不生成。

缩略图中应先读到纸面上的整体版式，再读到照片主体和一组明确的跨界线稿。若第一眼仍像原照片加了一层滤镜或建筑蓝图，构图失败。

## 作品资产使用协议

1. Bundled works 只供内部分析，不得附加到图像生成调用，不得上传到外部服务。
2. 从选中的作品资产提炼一至三个可见行为，例如跨边界线条、疏密反差或文字方向，并把它们写成纯文本提示。
3. 图像工具接收的图片数量严格等于用户为当前作品提供的图片数量；用户只上传一张时执行单图编辑。
4. 最终提示不得出现 bundled asset 路径、额外图片编号或“作品参考图”角色说明。
5. 不复制作品资产中的人物、建筑、物件、品牌、现成文字、语言、具体颜色和完整布局；作品资产与用户照片冲突时，以用户照片为准。
